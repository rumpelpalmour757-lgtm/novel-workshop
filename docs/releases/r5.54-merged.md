# 小说写作工坊 r5.54 合并候选版

版本号 `2026-11-14-r5.54-merged-candidate`。在 r5.54 的写法规则上，多带四个默认不开的模块的脚本、说明和测试：章节门、学习循环、示范记忆、对白声纹与反模式检查。

## 下载哪一个

- **`novel-workshop-commercial-r5.54-merged.zip`**：完整包，给能导入技能的工具用（Claude Code、Codex 一类）。解压后先运行 `python install.py --dry-run` 预览，再运行 `python install.py` 安装；要 Python 3.9 或更新。3,305,465 字节，SHA-256 `637cd100cee4c96c72714d6dad29a59d8ebe46eb5510c6cba704db1c76c63b5b`。
- **`portable-novel-workshop.md`**：便携单文件，给只能聊天、能传附件的 AI 用。没有可运行的脚本，也不带两个风格包。1,146,995 字节，SHA-256 `96b416de4edf93444484c7925471dc286825d7f3cd54325dbe1ea616324a5c55`。
- `LICENSE`、`THIRD-PARTY-NOTICES.md`：许可全文和第三方组件说明，和仓库根目录的同名文件相同。

装法、用法和第一条请求见[仓库首页](https://github.com/rumpelpalmour757-lgtm/novel-workshop)和[详细用法](https://github.com/rumpelpalmour757-lgtm/novel-workshop/blob/main/docs/usage.md)。

## 验证到哪一步

- 包内回归测试 1,429 项：1,424 项通过，5 项按条件跳过，在 Linux 上跑。测试只说明脚本照说明工作，不评价文学质量。
