# 小说写作工坊 r5.60

版本号 `2026-11-26-r5.60`。在上一版 r5.59（版本号 `2026-11-19-r5.59`，文件 `novel-workshop-commercial-r5.59.zip`）上做的新版本：技法卡分三个时候读（挑卡、起草、写完自查），可以先存成候选卡，改卡分轻重，起草流程里写明怎样用卡，节拍卡多一栏；风格卡的 `load` 默认只印方向，新加命令 `review`，照搬检查加了豁免表，配置里可以写一张全书固定的底色卡（`fixed_base_card`），卡片库照维护者认过的清单改了 17 张卡；示范记忆、判断卡、作者改法累计、事实账四份记录的说明页和模板修正；上锁的六节里只加了维护者认过的一句；章节确认和学习循环补上 r5.59 记下的那一种少见情形。工坊宪法正文没有改，仍是 NWC-1.8；改的脚本只有 `style_cards.py`。来由：维护者转来几份外部评估（对 r5.59 的技法卡模板、对技法卡在起草流程里怎样用、对风格卡体系、对示范记忆等四份记录）和一份外部的写作技法资料包，让制作方看对工坊有没有用。制作方逐条对着包里的页和脚本核过，给了建议，维护者定了：技法卡模板和用法照建议改，只收窄的改卡保留原来的采纳；风格卡的用法页和脚本照建议改，卡片库只改维护者在清单上认了的几条；四份记录照建议改说明页和模板，不碰脚本；那份资料包只借五处做法，原文一句不搬，脚本不运行；r5.59 记下的那一种少见情形补上条文。包里不写维护者的原话，也不写那几份评估出自哪里。包里把制作方叫编排方，把维护者叫作者；下面说“你”的地方，指写小说的人。

这一版做的验证比 r5.59 少：成对场景题只写了题面，没有答题和评分；章节门的各种情形没有实测；写作对照例没有整版跑。见下面“没有做的、没有验证的”。

## 改了什么

- **技法卡：分三个时候读，可以先存成候选卡，改卡分轻重**（`assets/technique-card-template.md`）：模板整份重排，原来的栏一栏没删。卡分上半（挑卡、起草、写完自查时读）、下半（建卡、改卡、复盘时读）和最底下一块“本书适配与使用记录”。上半开头写明三个时候各读哪几栏：挑卡读“什么时候拿出来用”“失效情境”；起草只读正面的几栏，另读一句固定的话“不搬原作的人物、台词和桥段”；写完自查拿“用过头的样子”核，看作用链走到没有。卡头的“管哪一样”多一类“叙述和描写”；卡头另加检索标签（拿不准写“不确定”），抄上工坊的判断、和模块的关系。卡的状态多“候选，没试写”“归档”“收进了规矩”；先存成候选卡至少填七栏，起草时不用，要用先补三样试写升成“可用”，门槛和一次填全的卡一样。改卡分轻重：只收窄的改动只补测新加的反例，你原来的采纳保留，下次交稿告诉你改了哪一句，你不同意就撤回这次改动；别的改动三样试写重做，采纳退回“没定”。你说过不要、撤回过采纳的卡不挑。“用过以后的问题”加一句：你只是不要照这张卡写出来的那几句、没说不要这张卡的，记在这里，“作者采纳状态”不记“作者不要”。模板是制作方起草、维护者看过的那一份，措辞维护者可以随时改；模板没有在真实拆文上用过。
- **“作用链”一栏加的一句**（同一份模板，维护者 2026-11-26 另认了加的）：末一环写成一件看得见的事（谁知道了什么，谁拿到或丢了什么，哪句话说出口收不回了）；只写得出情绪或气氛的，在“失效情境”里注明“这一手不推剧情”，挑卡时读得到。这一栏别的字没有动。照包内 `CHANGELOG.md` 写的经过：前半句照维护者看过的落进模板，一字没改；后半句和维护者看过的拟句有两处不一样：拟句没写这句注写在哪一栏，核对时发现挑卡不读“作用链”这一栏，所以写明注在“失效情境”里；拟句句尾说这样的卡撑不起一场，没有留，因为宪法 CON-011 写着对手戏、冲突戏以外的场靠关系、认知、行动准备或体验积累的变化立住，不带条件地这样说和它对不上。改好的整句已经给维护者看了，维护者不同意就照维护者看过的改回。这一句是收尾和上锁的那一句落包以后才落进模板的；落的时候整套测试和公开包查漏已经各跑过一遍，落完以后两样都重跑了。
- **起草流程里怎样用卡**（`references/drafting.md`“本章工作卡”里新加的“用技法卡”一段，`references/deconstruction-library.md`，`references/reference-study.md`）：本书有技法库时才读这一段。一张卡分三个时候读，各读哪几栏以卡上半开头为准；先按检索标签筛，只用工坊的判断是“可用”的卡；一场最多用两张，其余命中的只在节拍卡上记一笔，不读进起草；挑卡时也看“作者采纳状态”，你说过不要、撤回过采纳的卡不挑；模块在卡前面，卡和模块说法不一样时把两边的原句列给你，你定以前照模块办；同一处做法上，你采纳过的本书技法卡先于通用风格卡，挂了技法卡的场风格卡场景层最多一张；交稿时在正文外逐场说明用了哪张卡，你只要正文时记在工作记录里，例外两样：只收窄改过的卡那一句，用了你还没看过（或看过没定）的卡那一句。技法库的索引带卡头的“管哪一样”、检索标签和状态，照卡头抄，对不上以卡为准；技法卡的“候选，没试写”和判断卡的候选不是一回事。起草页原有的句子没有动。
- **节拍卡多一栏，交稿说明多一项**（`assets/scene-beat-card.md`，`references/scene-dramaturgy.md` 第 4 节，`references/editing.md`，`SKILL.md`，`references/chapter-confirmation.md` 七阶段表第 3 阶段那一格）：节拍卡加一栏“这一场用的技法卡”；交付门的脚本没有改，不核这一栏，它和卡一起在任务开始时冻结。交稿说明加一项“用了哪张技法卡、这一轮改过的卡”；“只要正文”那一句后面加上面说的两样例外。第 3 阶段那一格加半句：各场挑定拿来写的技法卡记在节拍卡上，列给你看不算你的采纳，确认这一阶段的“继续”“好”也不算对卡的采纳。分场规范第 1—3 节的照录原文没有改。
- **技法卡的两张单**（`references/quality-loop.md`“整理一次：交作者定”末尾）：本书有技法库的，做这一步时顺带列两张单交你逐张定：用过几回、你都采纳了的卡，问要不要收进规矩；很久没用过的卡，问要不要归档。工坊只列，不改卡的状态；收进规矩先收进本书的写法约定，也就是本书规则，写进哪一份由你定。照这一步原来的时候列，不定时跑，工坊不自己跑。上锁的“交付状态”一节没有动。
- **技法卡这一块另外要知道的**：交付门卡和改稿卡这一版没动，卡上“只要正文就只交正文”没有写技法卡的两样例外，只照卡做的时候读不到；上锁的“交付状态”一节也没有写。起草时不读反面几栏，是怕反面的话写得越具体、越容易被勾着写出来，这一点在工坊里没有验证过。这一块的用法都没有在真实章节上用过。从那份资料包借的五处做法是：交稿时在正文外说明用了哪张技法卡；同一场不该一起用的卡写进“失效情境”；写完自查时看作用链走到没有；索引照卡头抄、对不上时以卡为准；拆参考作品时试问拿掉这手法少了什么。都用工坊自己的话写，例子都是新写的，没有带它的原文、例子、模板和脚本，也没有带按字数、次数、比例定的门槛。

- 已经装过旧版的，用 `python install.py --upgrade`（装的时候带了 `--dest` 的也带同一个；先加 `--dry-run` 看输出，技能后面写 `upgrade` 或 `unchanged` 才对）。不加 `--upgrade` 时，装着的版本和这一版不同，安装器就停下，什么也不装。
- **从 r5.59 升上来**：先 `python install.py --upgrade --dry-run` 看一遍，再 `python install.py --upgrade`。装着的 `assets/project-packs/`（`_author/` 和你放进去的作品资料）照旧带进新版。交付记录照旧：五个绑定脚本和宪法正文没有变。登记表变了（`note` 末尾多了一句）：r5.59 时开始的交付门任务，`status` 的 `governance_warnings` 里会有一条“宪法或规则登记在任务开始后变了（开始时版本 NWC-1.8，现在 NWC-1.8）”。两个版本号一样，是因为宪法没变、登记表变了；只是提示，四项状态、阶段和权限裁决不变（用合成任务实际跑过）。
